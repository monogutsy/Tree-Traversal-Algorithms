This repository contains implementations of the three fundamental **Depth-First Search (DFS)** tree traversal algorithms commonly used in binary trees:

- **Pre-Order Traversal**
- **In-Order Traversal**
- **Post-Order Traversal**

These algorithms are foundational for understanding tree data structures and are widely used in expression trees, binary search trees (BSTs), and various algorithmic problems.

---

## 📂 About the Project

This project provides clear and simple implementations of the common DFS tree traversal algorithms. It’s ideal for:

- Students learning tree data structures  
- Developers revisiting DFS/traversal logic  
- Anyone needing ready-to-use traversal code  

---

## 🔍 Traversal Types

### 1. Pre-Order Traversal (Root → Left → Right)  
Visits:
1. The root node  
2. The left subtree  
3. The right subtree  

**Use-cases:**
- Copying a tree  
- Prefix (Polish) notation  

---

### 2. In-Order Traversal (Left → Root → Right)  
Visits:
1. The left subtree  
2. The root node  
3. The right subtree  

**Use-cases:**
- Getting sorted output from a BST  

---

### 3. Post-Order Traversal (Left → Right → Root)  
Visits:
1. The left subtree  
2. The right subtree  
3. The root node  

**Use-cases:**
- Deleting or freeing the tree  
- Postfix notation
